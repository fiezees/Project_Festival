# Instruksi Pembuatan Sistem WebGIS Festival Penanaman Pohon (Versi Demo)

## 1. Konteks Proyek
Sistem ini adalah sebuah portal acara untuk **Festival Tanam Pohon** yang menjadikan fitur WebGIS (pemetaan) sebagai komponen utamanya[cite: 4]. Sistem ini merupakan hasil adaptasi dan perombakan dari basis kode WebGIS spasial sebelumnya. 

Untuk versi demo ini, sistem akan berfokus pada **100 titik sampel** di wilayah Kecamatan Pauh (Batu Busuk, Lambung Bukit, Gunung Nago) dan Kecamatan Kuranji (Gunung Sarik), Kota Padang[cite: 4]. 

Target sistem meliputi antarmuka portal acara sederhana (Tab: Home, WebGIS, Login)[cite: 4] dengan interaktivitas pemetaan yang menggunakan *Tech Stack* yang sama dengan proyek sebelumnya.

---

## 2. Arsitektur & Tech Stack (Diadaptasi dari Sistem Sebelumnya)

Sistem tetap mempertahankan arsitektur 3 lapis:
`Browser (Leaflet) ⇄ Next.js Frontend ⇄ Express.js Backend ⇄ MySQL 8.0+ (Spatial)`

### Backend (Node.js + Express)
*   **Database:** MySQL 8.0+ atau MariaDB 10.5+ yang memanfaatkan fitur *spatial built-in* (`POINT`, `POLYGON`, dan fungsi `ST_AsGeoJSON`)[cite: 1, 3].
*   **Driver & Middleware:** Menggunakan `mysql2/promise` untuk koneksi asinkron, dan `cors` agar frontend dapat mengambil API tanpa kendala[cite: 1].
*   **Logika GeoJSON:** GeoJSON FeatureCollection dirakit di sisi Node.js setelah mengambil string JSON spasial dari *database* (untuk menjaga kompatibilitas lintas versi *database*)[cite: 1].

### Frontend (Next.js 14 App Router)
*   **Framework UI:** Next.js 14 dengan Tailwind CSS untuk pengaturan gaya[cite: 2].
*   **Peta:** Menggunakan `leaflet` dan `react-leaflet`[cite: 2]. Komponen peta di-*render* di sisi klien (*client-only*) dengan `next/dynamic` (`ssr: false`) agar terhindar dari *error* ketiadaan objek `window`[cite: 2].
*   **Interaktivitas:** Peta menampilkan marker, poligon batas wilayah, panel statistik, fitur pencarian/filter, serta panel detail (popup)[cite: 2, 3].

---

## 3. Struktur Database Baru

Buat *database* `festival_pohon_db`. Tabel spasial harus menggunakan `SRID 0` untuk menghindari masalah *axis-order swap* antara MySQL dan Leaflet (EPSG:4326)[cite: 1]. 

Berikut adalah skema tabel pengganti:

1.  **Tabel `batas_wilayah`** (Tipe geometri: `POLYGON`)
    *   Kolom: `id`, `nama_wilayah`, `kecamatan`, `luas_ha`, `geom`.
2.  **Tabel `titik_tanam`** (Tipe geometri: `POINT`)
    *   Kolom: `id`, `nama_peserta`, `jenis_pohon`, `umur_tanam_bulan`, `jangka_hidup_tahun`, `geom`[cite: 4].

*(Catatan untuk Agent: Silakan inisialisasi tabel di atas dan generate 100 data dummy berkoordinat di kisaran area Padang: Longitude 100.39 s/d 100.48, Latitude -0.92 s/d -0.88)*.

## 4. Tugas Modifikasi Backend (REST API)

Buatlah *endpoint* berikut berjalan di port `3001`[cite: 1]:

1.  **`GET /api/wilayah`**: Mengembalikan GeoJSON `FeatureCollection<Polygon>` dari tabel `batas_wilayah`.
2.  **`GET /api/tanam`**: Mengembalikan GeoJSON `FeatureCollection<Point>` dari tabel `titik_tanam`.
    *   Harus mendukung filter opsional `?jenis=` untuk memfilter marker berdasarkan jenis pohon.
3.  **`GET /api/stats`**: Mengembalikan JSON statistik agregat:
    *   Total keseluruhan pohon yang ditanam.
    *   Total per `jenis_pohon` (contoh: total Mahoni, Trembesi, dll).
    *   Total luas hektar dari `batas_wilayah`.

## 5. Tugas Modifikasi Frontend

Frontend berjalan di port `3000`[cite: 2]. Lakukan implementasi berikut:

1.  **Struktur Halaman Utama (Portal Acara):**
    *   Buat kerangka antarmuka responsif[cite: 4] yang memuat navigasi atas (*Header*) dengan tab: **Home**, **WebGIS**, dan **Login**[cite: 4].
    *   Untuk demo, fokus fungsionalitas berada di *tab* WebGIS.
2.  **Penyesuaian Komponen Peta (`Map.jsx`):**
    *   Ubah pusat peta (*center*) mengarah ke Kota Padang (sekitar `[-0.91, 100.46]`).
    *   Ganti pengelompokan warna marker yang sebelumnya berdasarkan kelas kondisi (sehat/sakit)[cite: 2], menjadi berdasarkan `jenis_pohon`. 
    *   Pastikan konfigurasi *fix* ikon bawaan Leaflet diterapkan untuk bundler Next.js[cite: 2].
3.  **Interaktivitas & Panel Informasi:**
    *   **Popup / Detail Panel:** Saat marker pohon diklik, tampilkan informasi: ID, Nama Peserta, Jenis Pohon, Umur Tanam, Jangka Hidup[cite: 4], dan koordinat.
    *   **Sidebar / Right Panel:** Modifikasi panel statistik untuk menampilkan perhitungan total per varietas pohon, kotak legenda warna jenis pohon, dan kotak centang (*checkbox*) untuk menampilkan/menyembunyikan jenis pohon tertentu[cite: 2, 3].
