# Dokumen Catatan Revisi Website Galapagos & Festival Tanam Hulu

Dokumen ini berisi daftar instruksi revisi antarmuka (*UI*) dan konten untuk situs web **Galapagos** dan **Festival Tanam Hulu**.

## 1. Struktur Navigasi & Halaman Organisasi

* [ ] **Penyesuaian Navigasi Utama**
  * Ganti menu navigasi untuk memfasilitasi 3 tingkatan organisasi:
    1. **Yayasan**
    2. **Perkumpulan**
    3. **SISPALA (Simpala)**

* [ ] **Penambahan Halaman Tingkatan Organisasi**
  * Buat **halaman baru** khusus untuk menjelaskan alur/struktur tingkatan organisasi dari Yayasan hingga SISPALA.
  * Lengkapi konten di masing-masing tingkatan:
    * Anggota/Pengurus Tingkat **Perkumpulan**
    * Anggota/Pengurus Tingkat **Yayasan**
    * Anggota/Pengurus Tingkat **SISPALA**

* [ ] **Retensi Halaman Existing**
  * Pertahankan halaman-halaman yang sudah dibuat sebelumnya (jangan dihapus).

## 2. Revisi Landing Page / Halaman Utama Galapagos

* [ ] **Penyesuaian Teks Headline Utama**
  * Ubah teks dari `"Halo! Kami Yayasan Galapagos."` menjadi **`"Halo! Kami Galapagos."`** (*hapus kata "Yayasan"*).

* [ ] **Pengantian Visual Latar Belakang (Background)**
  * Batal menggunakan banner.
  * Ganti motif garis-garis bergelombang (*wavy background pattern*) pada latar belakang dengan gambar **watermark1**, **watermark2**, **watermark3**, dan **watermark4**.

* [ ] **Trigger/Link ke Website Festival**
  * Pada elemen/card terkait di halaman Galapagos, pastikan pemicu (*trigger*) klik mengarahkan pengguna langsung ke situs web **Festival Tanam Hulu** menggunakan logo/banner festival.

## 3. Revisi Halaman Website Festival Tanam Hulu

* [ ] **Pengantian Logo**
  * Ganti logo website Festival Tanam Hulu dengan **logo baru** yang dikirim oleh Ibuk.

* [ ] **Penyesuaian Headline Utama**
  * Ubah teks headline dari `"Menanam Hari Ini, Menjaga Air Esok Hari"` menjadi:
    > **"menyemai lereng, selamatkan padang"**

* [ ] **Revisi Teks Section Lokasi ("Empat Lokasi, Satu Gerakan")**
  * Pada paragraf deskripsi di bawah judul section, ganti frasa `"empat lokasi strategis di..."` menjadi:
    > **"kawasan aksi tanam hulu"**

* [ ] **Penghapusan Komponen Hadiah & Uang Transaksional**
  * Hapus **seluruh section dan teks** yang menjelaskan informasi hadiah (termasuk section *"Apresiasi untuk Peserta Terbaik"*, nominal Uang Rp 100.000.000, informasi piala/trofi, sertifikat hadiah, dll.).

*Dokumen ini disusun sebagai panduan checklist bagi tim pengembang web (developer & designer).*
